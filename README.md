# ASLENIX Attendance Management System

Enterprise employee attendance, leave tracking, and task management system built with Spring Boot, Spring Security, Thymeleaf, and JPA/Hibernate.

## Tech Stack

- **Backend**: Spring Boot 4 / Java 25
- **Security**: Spring Security 6 (BCrypt, role-based authorization)
- **Database**: Dual-compatible with PostgreSQL and MySQL via Hibernate JPA
- **Templating**: Thymeleaf + Thymeleaf Layout Dialect
- **Deployment**: Docker, fully configured for [Render](https://render.com/)
